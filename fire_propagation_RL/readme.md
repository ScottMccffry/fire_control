# Wildfire Prediction Using Reinforcement Learning

## Project Overview
This project aims to predict the spread of wildfires using data from Google Earth Engine and a reinforcement learning model. The data includes current fire state, elevation, wind, and humidity.

## Directory Structure
- `data/`: Contains the data files extracted from Google Earth Engine.
- `scripts/`: Contains the Python scripts for data collection and training.
- `results/`: Contains the results of the training process.
- `requirements.txt`: List of required Python packages.
- `README.md`: Project description and setup instructions.
